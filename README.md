# DongPiece

A One Piece inspired browser-based text RPG game built with JavaScript, HTML, and CSS.

##Features
- Progressive Storyline
- Turn-based combat with randomized damage
- Scaling enemy difficulty and a leveling system that increases player stats
- Inventory system and item store, updating dynamically through DOM manipulation

## How to Play
Start by purchasing a weapon from the store. Fight opponents, travel to new islands, and progress through the story. Attack, defend and heal during fights. Sell unneeded items directly from the inventory tab for extra gold. 

## Built with
JavaScript, HTML, CSS

## What I Learned
- Updating the page dynamically with DOM Manipulation
- Modeling game elements as JavaScript objects
- Organizing game logic into reusable functions
